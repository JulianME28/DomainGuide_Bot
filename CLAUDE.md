# CLAUDE.md — правила роботи над проєктом DomainGuide_Bot

Цей файл — інструкція для Claude Code і водночас пам'ятка для власниці проєкту.
Мова спілкування — **українська**. Пояснення — **простою мовою, без жаргону**
(рівень: людина вперше бачить Python).

---

## 1. Що це за проєкт

Telegram-бот (aiogram 3) для аналізу донорських баз під SEO/linkbuilding.
Читає Google Sheets у режимі «тільки читання» і повертає **виключно агреговані
показники**: скільки донорів, середній DR, середній трафік, розподіли.

**Повне ТЗ:** [docs/tz.md](docs/tz.md) — джерело правди по функціоналу.
**Архітектура:** [docs/architecture.md](docs/architecture.md).

## 2. НЕПОРУШНІ ПРАВИЛА (порушувати не можна ніколи)

Ці правила важливіші за будь-яку зручність, швидкість чи «красу коду».

### 2.1. Секрети

- `.env` і `credentials.json` **ніколи** не потрапляють у git. Вони в `.gitignore`
  ще до першого коміту.
- У коді **немає** жодного токена, ID таблиці, ключа чи списку користувачів.
  Тільки читання з `.env`.
- `.gitignore` містить `*.json` — тому **жодних .json-файлів у репозиторії**.
  Тестові дані зберігаємо у `.py`-файлах, не в JSON.
- Перед кожним комітом перевіряти: `git status` не показує `.env`/`*.json`.

### 2.2. Домени не витікають

- Колонка `Domain` — **службове поле**. Використовується лише щоб визначити
  доменну зону.
- Домен **ніколи** не виводиться користувачу і **ніколи** не пишеться в лог.
- Це забезпечено **структурно**: шар аналітики повертає об'єкт `AggregateResult`,
  який фізично не містить списку донорів. Шар відображення просто не має доступу
  до доменів. Не ламати цю межу.
- Повний список донорів не видається **ніколи**, за жодних умов.

### 2.3. Тільки дозволені колонки

- Читаємо лише колонки з whitelist у `config/columns.toml`.
- Все, що не в whitelist, — не читається і не зберігається в пам'яті.

### 2.4. Доступ

- Працює тільки для Telegram ID зі списку `ALLOWED_USER_IDS` у `.env`.
- Стороннім бот не відповідає взагалі.
- Адмін-функції — лише для `ADMIN_USER_IDS`.

### 2.5. Бот не падає

- Будь-яка помилка (немає інтернету, впав Google, битий рядок у таблиці,
  порожній аркуш) → зрозуміле повідомлення користувачу, запис у лог, робота далі.
- Порожній аркуш — це коректний результат «0 донорів», а не помилка.

## 3. Модель ГЕО — головна особливість проєкту

**У даних НЕМАЄ колонки країни/гео і не буде.** Країна виводиться з двох
незалежних сигналів: **доменна зона** + **мова**.

### Правило двох чисел

| Тип запиту | Ядро результату | Додатково |
| --- | --- | --- |
| Країна («Німеччина», «.de») | донори в зоні `.de` | окремим **останнім** рядком: `💬 + N донорів німецькою мовою поза зоною .de` |
| Мова («німецькою», «German») | донори з мовою German | — |

**Два числа НІКОЛИ не сумуються.** Це різні множини, показані окремо.

**Без подвійного рахунку:** у мовний додаток входять лише ті донори, яких
**немає** в зоновому наборі.

**Попередження про спільні мови:** для `en`, `es`, `pt`, `ar` до мовного рядка
додається `⚠️ англійською пишуть багато країн, не лише Британія`.
Для однозначних мов (French, German) попередження немає.

**Глобальні зони** (`.com .net .org .online .site .info .eu .co .shop`) не
належать жодній країні й нікому не приписуються.

## 4. Порядок роботи (фази)

Проєкт будується фазами. Кожна фаза закінчується однаково:

1. `ruff check . --fix` і `ruff format .` — чистий код;
2. `pytest -q` — усі тести зелені;
3. **окремий коміт** із коротким повідомленням українською;
4. **автопуш**: після КОЖНОГО успішного коміту на `master` (тести зелені, ruff
   чистий) одразу `git push origin master`, щоб робота завжди була зарезервована
   на GitHub. Якщо пуш не проходить — не приховуй, доповідай.

Фази:

| # | Фаза | Що всередині |
| --- | --- | --- |
| 1 | Дані | читання Sheets, парсери брудних даних, кеш |
| 2 | Аналітика | фільтри, агрегати, модель гео |
| 3 | Словник | мови, країни, зони, резолвери, вільний текст |
| 4 | Рекомендації | суміжні країни, пониження метрик, дефіцит |
| 5 | Бот | меню, хендлери, майстер-запит (FSM), адмінка |
| 6 | Документація | README, архітектура, інструкція |

## 5. Стиль коду

- Python 3.11+ (у проєкті — 3.14).
- `ruff` — єдиний лінтер і форматер. Довжина рядка 100.
- Типізація обов'язкова для публічних функцій.
- **Докстрінги та коментарі українською**, простою мовою — код має читатися
  як пояснення. Це навчальний проєкт, зрозумілість важливіша за лаконічність.
- Назви змінних і функцій — англійською (стандарт Python).
- Без «розумних» однорядкових конструкцій, якщо є зрозуміліший варіант.
- Кожен модуль починається докстрінгом: що робить і навіщо.

## 6. Тести

`pytest` + `pytest-asyncio`. Тести працюють на **фейковому датасеті**
(`tests/fixtures/`), справжня таблиця в тестах не використовується — тести мають
працювати без інтернету й без ключа.

Обов'язковий мінімум (це «страховка» від регресій у ключовій логіці):

- зонове й мовне число окремі й **не сумуються**;
- мовний додаток **виключає** тих, хто вже в зоні;
- `en` дає попередження, `fr` — не дає;
- Turkish / Chinese / Vietnamese розпізнаються;
- глобальні зони нікому не приписані;
- **домен не витікає** у відповіді;
- порожній аркуш = 0 донорів без падіння;
- бот стартує **без** колонки GEO.

## 7. Спілкування з власницею

- Пояснювати простою мовою, з прикладами. Термін — одразу розшифровувати.
- Не питати про дрібниці, які можна вирішити самому.
- Питати **тільки на справжніх розвилках** — там, де вибір змінює результат
  і його неможливо вивести з ТЗ.
- Якщо ТЗ і уточнення власниці суперечать одне одному — **уточнення власниці
  головніше**, а розбіжність зафіксувати в `docs/architecture.md`.
- У кінці роботи: дерево файлів із поясненням, що дописати в `.env`, команда
  запуску.

## 8. Відомі розбіжності ТЗ ↔ реальність

| ТЗ каже | Реальність | Рішення |
| --- | --- | --- |
| є колонка «гео» | колонки гео немає і не буде | гео виводиться із зони + мови (розділ 3) |
| «Морди»: аналіз заспамленості, вихідні лінки | у «Мордах» ті самі 4 колонки, лінків немає; аркуш порожній | кнопка є, але чесно повідомляє, що колонка не підключена; вмикається сама, щойно з'явиться в `columns.toml` |
| LLM для вільного тексту | `LLM_PROVIDER=none` | вільний текст розбирається словником і правилами, без LLM; інтерфейс під LLM залишено |
| «Сабміти» — база | не читається | заглушка в меню |
